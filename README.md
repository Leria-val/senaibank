# Senaibank
Senaibank é uma fintech que gerencia, transfere, exclui e recebe transações bancárias, depósitos e consulta de saldo.

## Funcionalidade 
- Criar conta bancaria
- Listar contas bancarias
- Criar conta bancaria
- Atualizar dados
- Excluir conta
- Depositar dinheiro
- Sacar dinenheiro
- Transferir dinheiro
- Consultar saldo
- Emitir extrato bancario

## Tecnologias
- Java / Node.js
- Visual Studio / Github / Trello

## Como executar o projeto:
1. Clonar o repositorio
https://github.com/Leria-val/senaibank

2. Entrar na pasta do projeto:
cd senaibank

3. Executar o projeto:
Instalar dependências:
npm install

Executar o projeto:
 npm start

##  Estrutura do projeto
 src/ - código fonte 
 models/ - estrutura das contas 
 services/ - regras de negócio 
 controllers/ - controle das operações
